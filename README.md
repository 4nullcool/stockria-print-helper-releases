# Stockria Print Helper — Releases

Binary-only repository for the [Stockria Print Helper](https://stockria.com/) desktop app.

- macOS and Windows installers attach to each tagged release.
- Released via GitHub Actions from the main Stockria monorepo.
- `latest-mac.yml` / `latest.yml` / `latest-linux.yml` power in-app auto-update via `electron-updater`.

First-time install on macOS: right-click the app → Open to bypass Gatekeeper.
